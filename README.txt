ROMAN FENCE CO ESTIMATE APP — VERSION 1.0

To run: Double-click index.html. It works offline in Chrome, Edge, and other modern browsers.

Features:
- Five fence runs with end/corner/shared post selection
- Independent front-of-house setbacks and live schematic layout
- Walk gates and double drive gates on home-to-fence returns
- Double gate: 2 gate leaf panels, 2 gate kits, and 1 $40 drop rod
- White/tan vinyl material calculations, tax and labor
- Vendor order copy/email, printable estimate, JSON save/load
- Browser autosave (localStorage)

IMPORTANT: Preliminary material estimate only. Shared physical post connections, gate post geometry, gate panel fabrication, real-to-scale site drawing, concrete requirements, and tax applicability require field verification. The diagram is illustrative. The app is not hosted online; open index.html locally.
